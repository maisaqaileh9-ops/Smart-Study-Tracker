# Smart Study Tracker 📚

A Python desktop application for tracking study sessions, monitoring progress, and managing weekly study goals.

## ✨ Features

- Add study sessions
- Edit study sessions
- Delete study sessions
- Search study records
- Sort records by date or study hours
- Calculate study averages
- Set weekly study goals
- Track weekly goal progress
- View study statistics through a dashboard
- Get smart study feedback
- Export a study report
- Store data using CSV files
- Input validation
- Automatic study session numbering

## 🖥️ Application

Smart Study Tracker provides a simple graphical interface built with Tkinter.

The application includes:

- 📚 Study session management
- 📊 Dashboard and statistics
- 🎯 Weekly study goals
- 🔎 Search and sorting
- ✏️ Editing records
- 🗑️ Record deletion
- 📄 Report export

## 🛠️ Technologies
